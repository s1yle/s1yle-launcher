# WeCraft! Launcher

[![Version](https://img.shields.io/badge/version-0.1.0-blue.svg)](https://github.com/s1yle/WeCraft-Launcher/releases)
[![License](https://img.shields.io/badge/license-GPL--3.0-green.svg)](LICENSE)
[![Build](https://img.shields.io/github/actions/workflow/status/s1yle/WeCraft-Launcher/release.yml?label=CI)](https://github.com/s1yle/WeCraft-Launcher/actions)

Contains the full frontend + Rust backend source of the launcher, covering version management, download engine, Minecraft launch, UI library, theming, and accessibility.
Code is synced on each release. Open-sourced under GPL-3.0. Community support is welcome!

- 🎮 **Accounts**: Microsoft / offline / third-party, tokens stored in the OS keyring
- ⬇️ **Downloads**: game versions & Fabric/Forge/NeoForge loaders, chunked concurrency + SHA1 verification
- 🗂 **Instances**: PCL-style directory layout, shared global resources
- 🚀 **One-click Launch**: versioned dir startup with log capture
- 🎨 **Theming + Accessibility**: dark/light/terminal themes, photosensitive/high-contrast, font scaling to 200%
- 🏝️ **Dynamic Island Navigation**: floating glassmorphic nav

> ☁️ Cloud modules such as Community Servers and the Server Owner Dashboard are coming in later releases.
