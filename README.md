# WeCraft! Launcher

[![Version](https://img.shields.io/badge/版本-0.1.0-blue.svg)](https://github.com/s1yle/WeCraft-Launcher/releases)
[![License](https://img.shields.io/badge/许可证-GPL--3.0-green.svg)](LICENSE)
[![Build](https://img.shields.io/github/actions/workflow/status/s1yle/WeCraft-Launcher/release.yml?label=CI)](https://github.com/s1yle/WeCraft-Launcher/actions)

包含启动器的完整前端 + Rust 后端源代码，涵盖版本管理、下载引擎、Minecraft 启动、UI 库、主题与无障碍等模块！
代码会在每次发布时同步一次。GPL-3.0 开源，欢迎社区支持！

> ☁️ 社区服务器、服主后台等云端模块将于后续版本开放。
